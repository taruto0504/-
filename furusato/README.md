# ふるさと還元チェッカー

ふるさと納税の返礼品の「寄附額」と、同じ商品のネット通販の「市場価格」を入れるだけで、還元率・単価・判定（参考）が分かるアプリです。
企画書（2026-10-23）をもとに作った最初の版です。

## できること

| 機能 | 内容 |
| --- | --- |
| 還元率計算 | 市場価格 ÷ 寄附額 × 100。標準還元率30%と並べ、差を「＋〇〇ポイント」で表示。ゲージに30%の線 |
| 計算の正確性 | 入力の確認 → 円の整数のまま計算（丸めは最後に1回・四捨五入）→ 逆算で検算 → 途中式を必ず表示。検算が合わなければ結果を出さない |
| 桁違いの確認 | 寄附額1,000円未満・還元率100%超・3%未満は「この金額で合っていますか？」を出す |
| 市場価格が見つからない時 | 入れ方を切り替え：①似た商品の単価（例 100gあたり198円）× 内容量で市場価格を推定し、結果・履歴・シェアに「推定」と表示 ②寄附額（と内容量）から「還元率40%・30%・20%になる市場価格・単価」を逆算（切り上げ・検算つき） |
| 送料・定期便 | 送料を足す。定期便は1回分／全回分を選べ、1回あたりの寄附額・価値も表示 |
| 単価比較 | g・kg・ml・L・合・升・個・本・パック・人前・円分・泊など。「300g×4パック」「約1.2kg」「1〜1.5kg」も計算。換算は逆換算で検算 |
| 写真・スクショ取り込み | 端末内OCRで金額・内容量・回数の数字だけを読み、画像上に色枠で表示。読み間違い（円→F、g→9、O→0 など）に確認マーク。枠をタップして1タップで修正。複数枚は還元率順・単価順に並べる。2枚（寄附額だけ・価格だけ）は1件にまとめる |
| 判定・標準アドバイス | 高め（40%以上）／やや高め（30%以上）／標準的（20%以上）／控えめ。色＋記号＋文字で表示 |
| AIアドバイス | Claude・ChatGPT・Gemini から選び、自分のAPIキーで端末から直接呼ぶ。送るのは数字だけ。キーは端末内に暗号化保存。失敗時は標準アドバイスのまま |
| サイト一覧 | 五十音順の固定 or 自分で並べ替え。ロゴは使わず文字アイコン |
| シェア | 数字だけの画像カード（1080×1080）またはテキスト |
| 履歴・比較 | 数字だけを保存（商品名は保存しない）。新しい順・還元率順・単価順（同じ単位どうし） |
| 表示 | 文字サイズ3段階、ダークモード、主なボタンは画面下 |

## フォルダ

```
furusato/
  index.html            画面
  css/app.css
  js/calc.js            還元率の計算・検算・判定・設定ファイルの検証
  js/units.js           内容量の読み取りと単位換算
  js/ocr-parse.js       OCRの結果から数字を拾う
  js/ocr.js             端末内OCR（vendor/tesseract を使用）
  js/ai.js              AIアドバイス
  js/storage.js         端末内の保存（APIキーの暗号化）
  js/config.js          設定ファイルの読み込み
  js/share.js           シェア用の画像カード
  js/app.js             画面の動き
  config/app-config.json  基準値・しきい値・単位の換算表・サイト一覧
  vendor/tesseract/     端末内OCRの部品と日本語・英語の文字データ（npm run vendor で作成）
  tests/                計算の例題集（自動テスト）
```

## 動かし方

```sh
cd furusato
npm install
npm test          # 例題集のテスト
npm run serve     # http://localhost:8080 で確認
```

Web版はリポジトリの GitHub Pages で `/furusato/` に置けばそのまま動きます（オフライン対応・共有メニューからの画像受け取りつき）。

## スマホアプリ（iPhone / Android）にする

企画書では Flutter を案にしていましたが、このリポジトリの既存アプリと同じ **Capacitor** の構成にしました（Web版とアプリ版を同じコードで作れ、計算部分を自動テストで確かめやすいため）。

```sh
cd furusato
npm install
npx cap add ios        # 初回のみ（Mac）
npx cap add android    # 初回のみ
npm run sync
npm run open:ios       # または npm run open:android
```

アプリ版では次の作業が残っています。

- 他のアプリの共有メニューから画像を受け取る：iOS は Share Extension、Android は intent-filter を追加し、受け取った画像を `furusato-shared-images` イベント（`detail.files`）で画面に渡す
- APIキーの保存先：今は WebCrypto で暗号化して端末内に保存。アプリ版では Keychain / Keystore を使うプラグインに置き換えるとより安全
- 端末内OCR：今は Tesseract（同梱）。精度を上げたい場合は iOS Vision / Google ML Kit のプラグインに置き換え、`js/ocr.js` の `recognize()` と同じ形（行と単語の位置）を返せば残りはそのまま使える

## 設定ファイルの変更

`config/app-config.json` で、標準還元率・判定のしきい値・注意文・単位の換算表・サイト一覧を変えられます。

- 変更したら `version` を新しい日付にする（アプリ版は新しい version の配信版だけを使う）
- 変更後は必ず `npm test` を通す（GitHub Actions でも自動で実行）
- 形が壊れた設定は `validateConfig` が弾き、手元の設定のまま動く
