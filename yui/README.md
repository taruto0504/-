# Project YUI（仮称）— 3D AI コンパニオン

3Dキャラクターが画面の中を自由に動き回り、日常・仕事・学習を支えるパーソナル AI パートナーです。
企画書（2026-10-23）のロードマップ **フェーズ1「基本の画面と会話」** までを作った版です。

## フェーズ1でできること

| 機能 | 内容 |
| --- | --- |
| 3Dキャラクター | VRM（VRoid Studio などで作ったもの）を読み込んで表示。画面内をふわふわ移動・浮遊、まばたき、呼吸、腕を下ろした待機ポーズ、髪や服の揺れ（VRM の揺れもの）、視線が指・マウスを追う |
| 仮のキャラクター | VRM を読み込むまでは「光の精」の仮キャラクターが動く |
| 反応 | 考え中（首をかしげる）・話し中（口が動く）・うれしい（笑顔）。タップすると反応し、何もないところをタップするとそこへ移動 |
| 近未来の背景 | 星空、光の粒が線でつながるネットワーク、地球（海・陸・夜の街明かり・大気の光）、漂う光の球。すべて3Dで描いて動かす |
| 時計 | 日付・曜日・時刻（秒まで）を常に表示。位置（四隅）・秒・表示の有無を変更可 |
| 時刻の声かけ | 起動時のあいさつ、7時・12時・15時・18時・22時・0時の一言、90分ごとの休憩の声かけ |
| AI設定（BYO-AI） | Claude・ChatGPT・Gemini から選び、自分の APIキーで端末から直接つなぐ。キーは端末内に暗号化して保存 |
| 性格設定 | 名前・呼び方・口調・性格、サポート目的（日程管理／書類／勉強／アプリ開発／投資ニュース／雑談）を選ぶと、AIへの指示を自動で組み立てる |
| テキスト会話 | 返答を少しずつ受け取り、すぐ吹き出しに出す。履歴は端末内に保存。途中で停止できる |
| 利用料の目安 | 使ったトークン数を表示。単価を入れると金額の目安も表示。送る会話は直近20件まで |
| 省電力・画質調整 | 端末の性能で画質を自動で決め、重い時は解像度を下げる。省電力モードで背景を止める。画面が見えていない間は描画を止める |
| 安全 | 健康は診断しない・投資は売買助言しない・深刻な相談は窓口を案内、をAIへの指示に固定。業務上の個人情報を入力しないよう常に表示 |

まだできないこと（次のフェーズ）：音声会話と口パク・記憶（フェーズ2）、管理アイコンとカレンダー連携（フェーズ3）、書類読み込み・ニュース・通知（フェーズ4）、同期・生体認証・アプリ化（フェーズ5）。

## スマホで使う

公開ページ：**https://taruto0504.github.io/-/yui/app/**

1. スマホのブラウザ（iPhone は Safari、Android は Chrome）で上のURLを開く
2. 共有ボタン →「ホーム画面に追加」（Android はメニュー →「ホーム画面に追加」）。アイコンから全画面で開けます
3. ⚙ →「AI」で APIキーを保存して話しかける

APIキー・会話・VRM はその端末の中だけに保存されます（端末間の同期はフェーズ5）。

## 開発


Node.js 22 以上が必要です。

```sh
cd yui
npm install
npm run dev        # http://localhost:5173 で開く（同じ Wi-Fi のスマホからは npm run dev -- --host）
npm test           # 時計・AIへの指示・通信の読み取りのテスト
npm run build      # app/ に公開用のファイルを作る（ソースを変えたら app/ もコミットする）
```

1. 右上の ⚙ →「AI」で使うAIを選び、APIキーを入れて保存
2. 「キャラ」で VRM ファイルを読み込む（なくても仮のキャラクターで使えます）
3. 画面下の入力欄から話しかける（Enter で送信、Shift+Enter で改行）

## フォルダ

```
yui/
  index.html
  src/
    App.tsx                 画面全体（吹き出し・会話・設定・声かけ）
    components/             時計・会話パネル・設定画面
    lib/ai.ts               AIサービスへの接続（ストリーミング）・利用料の目安
    lib/prompt.ts           性格とサポート目的からAIへの指示を作る
    lib/clock.ts            時計の表示・あいさつ・声かけ
    lib/settings.ts         設定の形と初期値
    lib/storage.ts          端末内の保存（APIキーの暗号化、VRMファイル）
    three/stage.ts          3D の舞台・キャラクターの移動・画質調整
    three/character.ts      VRM の読み込みとポーズ・表情、仮キャラクター
    three/background.ts     宇宙・ネットワーク・地球
  tests/                    テスト
```

## 技術

TypeScript ／ React ／ Three.js ＋ three-vrm ／ Vite。フェーズ5で Tauri（PC）・Capacitor（スマホ・タブレット）でアプリにします。
