# 医療シミュレーション

医療従事者・教育担当者・学生が、教育用の**架空の症例シナリオ**を作成・共有し、チャットで意見交換するためのアプリ（PC・スマホ対応のPWA）。

## 主な機能
- シナリオ作成：基本情報、バイタルサイン1・2（急変時）、音声入力、一時保存・下書き
- 完成したシナリオを1画面にまとめて表示。PDF・印刷はA4用紙1枚
- 送信相手・グループへの送信、送信後の編集の自動反映（変更箇所と履歴）、確認状況、共有の解除
- シナリオごとのチャット（既読数）、通知
- AI評価：入力の整合性チェックと解説。国内の診療ガイドライン（Minds掲載分を含む20件）の要点を根拠に使う
- 使い方モード、見本シナリオ、利用規約への同意、個人情報らしき入力の自動チェック、ダークモード・文字サイズ

## 動かし方
ビルドは不要です。このフォルダを静的ファイルとして配信し、`index.html` を開きます。

```sh
python3 -m http.server 8000
# http://localhost:8000/ を開く
```

データはブラウザの中（localStorage）に保存されます。AI評価には、マイページで Claude の APIキーを設定します（キーはその端末にだけ保存されます）。

## 注意
教育用のアプリです。実在する患者の情報は入力しないでください。AI評価やガイドラインの要点は参考情報であり、実際の診療判断には使用しないでください。
